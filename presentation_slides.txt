Slide: 4. Introduction
 Problem statement: Patients lack ownership of their medical data; providers struggle with data sharing across different systems; centralized servers are vulnerable to data breaches.
 Objectives: To build a secure, transparent, and interoperable EHR system that puts patients in control of their data.
 Goals: Empower patients with data ownership, ensure data integrity through blockchain immutability, and facilitate seamless, permissioned provider access.

Slide: 5. Literature Survey/Review
 Summary of existing solutions: Centralized databases (e.g., Epic, Cerner) are the standard but suffer from data silos and lack of interoperability.
 What others have done: Research into blockchain for healthcare (e.g., MedRec) has shown promise but often faces scalability issues.
 Gaps or limitations: Existing solutions often compromise between security and usability, or lack a truly patient-centric access model.
 How your project fills these gaps: Med Share Chain uses a hybrid approach (Blockchain + IPFS + MongoDB) to balance security, scalability, and user experience, ensuring patients control who sees their data.

Slide: 6. System Analysis
 Proposed system overview: A web-based Decentralized Application (DApp) with a mobile component.
 Software requirements: 
  - Frontend: React, Vite, Tailwind CSS
  - Backend: Node.js, Express, MongoDB
  - Blockchain: Solidity, Truffle, Ganache, Web3.js/Ethers.js
  - Storage: IPFS
 Hardware requirements: Standard PC/Server for hosting, Mobile device for client access.

Slide: 7. System Design
 System architecture diagram: Client (React/Expo) <-> Backend (Node/Express) <-> Blockchain (Ethereum Smart Contracts) & Storage (IPFS).
 Workflow: 
  1. User Registers (Patient/Provider)
  2. Patient Uploads Record -> IPFS (returns Hash)
  3. Hash Stored on Blockchain
  4. Patient Grants Access to Provider
  5. Provider Views Shared Record via Hash
 Module breakdown: Authentication Module, Record Management Module, Access Control Module (Smart Contract), IPFS Interface.
